## What is BRS?
Borealis Roleplay Studio is a Windows application that aims to aid the user in local role-playing sessions, including numerous helpful tools to maintain and organise character and world lore. 

You will also be able to local-host sessions and roleplay within the same wifi network with other users. 

A future online system for shared sessions over the internet is in the planning, but I need to see how that would work.
